## O que ando fazendo

- [Latex-ops](https://github.com/pv-ca/latex-ops): uma skill de agente para criar documentos em LaTeX bem acabados, com atenção à tipografia e ao layout.
- [Flexoki Rams](https://github.com/pv-ca/flexoki-rams): um tema para KDE Plasma 6 que usa as cores do Flexoki e um design inspirado em Dieter Rams. Em desenvolvimento inicial.
- [Linux-ops](https://github.com/pv-ca/linux-ops): uma skill de agente para administrar sistemas Linux, de pacotes e serviços a armazenamento, rede, hardware e diagnóstico. Em desenvolvimento inicial.
- [Business-ops](https://github.com/pv-ca/business-ops): um plugin para Claude Code e Codex com skills para vendas, marketing, sucesso do cliente e finanças.
